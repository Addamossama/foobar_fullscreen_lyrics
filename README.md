# foobar_fullscreen_lyrics
(coded heavily by ai)  
A fullscreen lyrics app for foobar2000 x86, made to provide a fullscreen music/lyrics experience without needing to work around SMTC or Windows media controls.

## General requirements

* foobar2000 32-bit with the Beefweb component  
https://www.foobar2000.org/components/view/foo_beefweb

**Default address:**

```text
http://127.0.0.1:8880
```

## Install

### 1.independent exe app

Install the release .zip,extract it ,then run the `.exe`.

### 2.independent script

**Requirements:**

* Python 3.10+
* Pillow >= 10.0
* Tkinter (bundled with Python on Windows/macOS; `python3-tk` on Linux).
* mutagen

Install the release .pyw.zip 
extract it.  
Just double-click .pyw  

### 3. As a component
Install the release .fb2k-component  
Install the component in foobar2000.
click view > Foobar Fullscreen Lyrics
